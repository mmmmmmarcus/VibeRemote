# vvhisper 0.3.7

- Sync Seed ASR and polishing keys, Polish Dictation, and Sentence Punctuation through a password-encrypted JSON file you select in iCloud Drive. Existing local keys continue working offline.
- Import and export encrypted configuration files using the shared Mac, iOS and Android format. Different existing keys pause sync for your choice rather than silently replacing them.
- Dictation failures now display a message, error code and Settings shortcut without taking typing focus or requiring notification permission.
- Missing Accessibility permission is detected before inserting dictation. Polishing failures explain that recognized text was retained, and readable editors can report unconfirmed insertion.

To set up file sync, open Settings → About → Sync and Transfer, choose Create Sync File, and save it in iCloud Drive. Link that same file in a compatible iOS build with the same password; open the iOS host app to receive changes. Android uses explicit file import/export. Keep the password: it cannot be recovered. No iCloud Keychain sync setup is required.

Requires an Apple Silicon Mac running macOS 27 or later. Siri Remote audio setup still requires your own Apple PacketLogger installation; it is not included in this download.

Live two-device iCloud delivery and the reported insertion issue on another Mac have not yet been verified. The mobile file format is implemented and tested; this release download is the Mac app.
