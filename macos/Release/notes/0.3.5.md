# vvhisper 0.3.5

VibeRemote is now vvhisper, with a refreshed app icon and dictation cursor.

- Choose the active microphone from the menu bar, including connected Mac inputs and Soundcore Work.
- Dictation can correct grammar and spelling and improve sentence flow while preserving your meaning. This optional step uses Seed 2.0 Mini and requires a separately configured Ark key.
- Pending dictated text stays underlined until processing finishes. Typing, Delete, or clicking to edit cancels pending dictation and polishing, preserving your edits against late results.
- Customize punctuation for short sentences and input gain for each Siri Remote model and Soundcore Work.
- Adjust device release buffers, use improved Soundcore reconnection, and configure each Siri Remote model independently.
- Updated settings organize Dictation, Dictionary, Computer Use and device controls separately.

## Compatibility and signing migration

Requires an Apple Silicon Mac running macOS 27 or later. Existing app identifiers, settings, and the Sparkle update feed are retained.

This release is signed by Haolin Fei (team Q9MD524YL5), replacing the former company signing identity. macOS may require renewed permissions and Keychain access. Existing privileged helpers may need Set Up / Repair Helper in Settings. The complete company-to-personal Sparkle and helper migration has not yet been verified on a separate older installation.

Downloads and installation remain your choice; automatic update checks do not enable silent installation.
