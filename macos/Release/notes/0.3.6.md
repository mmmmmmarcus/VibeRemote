# vvhisper 0.3.6

- About now shows permission status and controls for Input Monitoring, Accessibility, Bluetooth, Microphone, Speech Recognition and Screen Recording. Optional permissions explain which features need them.
- About also provides Siri microphone bridge start/restart, helper repair and Apple PacketLogger selection controls.
- Duplicate Bluetooth connection notifications no longer repeatedly restart Siri audio capture. Genuine disconnect/reconnect events still trigger recovery.
- Siri audio diagnostics now report the active capture path instead of incorrectly asking for Direct HID reports when PacketLogger is in use.

Requires Apple Silicon and macOS 27 or later. Signed by Haolin Fei (Q9MD524YL5). Existing settings are preserved. Upgrading from the former company-signed VibeRemote may require renewed macOS permissions and helper repair.

Siri Remote must be connected and its Siri button held for microphone audio. Apple’s signed PacketLogger is required for the capture path and is not redistributed in this release. Physical Siri microphone recovery remains unverified; automated tests and build checks passed.
