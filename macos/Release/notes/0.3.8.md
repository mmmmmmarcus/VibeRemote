# vvhisper 0.3.8

- Fix Seed ASR authentication after replacing an API key: an old saved App ID no longer makes the new key use legacy Access Token headers. This covers streaming, final refinement and one-shot recognition.
- Replacing a Seed key through encrypted configuration import or sync also clears stale legacy authentication after the credential writes succeed.
- Show a Keychain save error and retain the entered key if saving fails. Existing legacy credentials remain unchanged until you replace them.

If a new Seed API key previously failed, open Settings → Dictation and save it again after updating.

Requires an Apple Silicon Mac running macOS 27 or later. Existing settings and local keys are preserved. Siri Remote audio still requires your own Apple PacketLogger installation.
