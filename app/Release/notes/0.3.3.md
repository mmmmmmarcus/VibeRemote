## A simpler Settings window

- A narrower layout with matching glass menus for Siri Button and Auto disconnect.
- A green battery ring with a remote icon replaces the inline percentage. Hover over it for the exact reading.
- The remote preview shows button functions and a blue highlight on hover, with darker aluminum lighting and freer rotation that retains resistance and returns to its guide pose on release.
- Removed the remote-type heading and version section from Settings.
- Manual Check for Updates now lives in the More menu. Automatic checks remain enabled, with an Update button shown when an update is available.

For Apple Silicon Macs running macOS 27. Downloads and installation remain your choice.

The unchanged GPL audio driver’s corresponding source is included. Apple PacketLogger is not redistributed.
